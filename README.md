The World in One Page — 20 November 2026: a program that draws a one-page newspaper front page summing up the world's news of Friday 20 November 2026 as a 1024x1024 PNG, pixel by pixel, using only the Python standard library. No network access, fully deterministic — two runs write byte-identical files.

Lead story: the first Trump–Xi–Putin three-way summit in Shenzhen. Also on the page: the UN court's Myanmar genocide ruling, Cyclone Akvan's landfall in India, Anthropic's $1.5T stock market debut, a tanker burning after a mine strike east of the Strait of Hormuz, GTA VI's launch, Voyager 1 reaching one light-day from Earth, and Russian strikes damaging the Austrian and Dutch embassies in Kyiv.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
